STEP 2: Update .env File
-------------------------
After creating the apps, you'll have 6 credentials:
- Google Client ID
- Google Client Secret
- GitHub Client ID
- GitHub Client Secret
- LinkedIn Client ID
- LinkedIn Client Secret

Open your .env file and paste them in.

STEP 3: Verify Setup
--------------------
Run this command:
    .\check-oauth.ps1

This will check if your credentials are configured correctly.

STEP 4: Test OAuth
-------------------
1. Go to: http://localhost:3001/login
2. You'll see OAuth buttons appear automatically
3. Click any button (Google/GitHub/LinkedIn)
4. Sign in with that provider
5. You'll be logged in automatically!
